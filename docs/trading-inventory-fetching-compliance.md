## Behavioral evidence matrix

| Scenario                                             | Outcome / evidence                                                                                                                                                            |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Same-owner reload and expired saved entry            | No inventory restoration; a new live admitted load is required. Original source timestamps survive the response. Browser positive-control storage scan establishes exclusion. |
| Owner/session change or denial                       | Known denial/owner change clears local private results; browser journey and lifecycle tests verify no old view.                                                               |
| Unknown verdict / admission expiry                   | Retained memory stays hidden; renewal must return a current matching owner/fingerprint. Lifecycle tests distinguish suspension from clearing.                                 |

| Scope/organization/revision change and late response | Generation invalidation refuses old completion; cursor/guard and PostgreSQL lifecycle tests fence before release.                                                             |
| New observation / stale read                         | Changed observation requires restart; current/stale quantities stay separate; unsupported stale policy produces a gap.                                                        |
| Partial source / complete empty                      | Gap cannot become zero; complete empty is distinct. Source and real projection tests cover both.                                                                              |
| Cancel/deadline/queued authority loss                | No new pages/subjects after cancel; queued loads do not start; deadline refuses stalled work.                                                                                 |
| Small result with excessive source scope             | 21/251 subjects or source-page overflow refuse rather than silently truncating; aliases share the existing request budget.                                                    |
| Purge/re-entry/transfer/disablement                  | Current-authority checks revoke immediately; real PostgreSQL cascade and wrong-tuple tests protect physical cleanup. Target throughput is blocked.                            |
| Cross-tab invalidation                               | Host identity notification invalidates the live binding; there is no inventory persistence to restore. Focus/online recheck provides recovery.                                |
