## Findings and policy conflicts

No unresolved compliance defect was found in these added request paths. The checklist's older
repository-wide command examples and Compose rebuild advice are superseded by the current
root affected-scope verification policy. The latter requires focused affected checks and
reserves deployment probes for deployment/startup changes. This change adds migration contracts
verified on isolated PostgreSQL; no live deployment or policy enablement was requested.

Synthetic capacity uses real PostgreSQL with fake ESI and an accelerated scheduling model.
It does not establish live daily drain time. Real Redis tests separately exercise history
spacing, failure deferral and queue coalescing. Browser lifecycle and unrelated private,
organization, introspection or SDK package behavior are outside this review's changed scope.
