## Findings

The publication and polling regressions failed on the original implementation. The initial baseline's `publish-current-market-observation` operation returns `published`, `unchanged`, or `incomplete`. Resource materialization uses this operation. Unchanged observations do not replace the current pointer or create duplicate derived metrics.

Watched-profile scheduling is recomputed from current-revision pointers, so the final type cannot postpone an earlier expiry and replaced deadlines can advance. Missing required books remain discoverable as due.

History reentry rechecks the existing public history query and resumes polling if collection remains unfinished. Pending demand coalescing and polling-generation checks preserve one active loop across rapid tab changes.

Group-ID validation now matches the adjacent type-ID schema. The reported overflow-to-503 behavior was not reproducible with this checkout's Zod version because `.int()` already validates safe integer bounds.
