## Required commands

Run artifact-producing commands sequentially before dependent tests:

```bash
openspec validate harden-codebase-quality --strict
pnpm lint
pnpm format:check
pnpm knip
pnpm typecheck
pnpm test:frontend:coverage
pnpm test:api:coverage
pnpm --filter @eve-space/api test:postgres:coverage
pnpm test:modules:coverage
pnpm test:registry:coverage
pnpm test:redis
pnpm --filter @evespace/esi-client validate
pnpm --filter @eve-space/api build
pnpm build
pnpm test:e2e
cargo fmt --manifest-path sde-ingest/Cargo.toml --all --check
cargo clippy --manifest-path sde-ingest/Cargo.toml --all-targets --all-features --locked -- -D warnings
cargo test --manifest-path sde-ingest/Cargo.toml --all-features --locked
```

For accessibility evidence, exercise Chromium at `1280x800` and `390x844` across every runtime theme. Verify logical Tab and reverse-Tab order, skip-link focus, drawer focus containment and restoration, route-announcement text, unique titles, image alternatives, no horizontal overflow, normal-text contrast of at least 4.5:1, and focus-indicator contrast of at least 3:1. Use the deterministic browser fixtures rather than production credentials.
