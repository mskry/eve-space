# Organization Platform Traceability

This document maps every scenario in `add-organization-platform-foundation` to automated evidence.
Test titles are the stable references; line numbers are intentionally omitted. Run strict artifact
validation with:

```bash
openspec validate add-organization-platform-foundation --strict
```

## Verification Suites

The scenario evidence is exercised by task 10.3 through the root frontend, API unit/coverage,
PostgreSQL, Redis, module, registry, conformance, typecheck, and production-build commands. Runtime
deployment and route-boundary probes are recorded separately in the rollout verification section of
`docs/organization-platform.md`.
