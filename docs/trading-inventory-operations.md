The combined 20-page bound limits personal source volume to 20,000 wire rows, even where individual subjects permit ten pages. Corporation subject count does not promise support for arbitrary item volume: 25,000 projected rows is the measured representative case. Larger local datasets require new capacity evidence within existing deadlines.

No global budgets were raised: 32 backend invocations, concurrency four, 15-second operation deadline, 2 MiB memo and response bounds, 5,000 selected cost, 1,000 selected rows, 30 aliases and 12 read bindings. ## Rollback and privacy

Disable Trading to stop aggregate reads; disable Member Audit/assets through the existing administrator interface when revoking the source. Existing enablement and release checks fence retained or in-flight results. Keep paired API/worker/Nuxt artifacts: an older worker must not continue under a newer incompatible installed persistence contract. Pause collection before switching compatible binaries and let the API own migration/attestation reconciliation before starting the worker.

Rollback is an application rollback retaining additive tables, migration ledgers and audit history. Do not drop the migration, change the organization version back, delete audit rows, or remove Compose volumes. Older asset promotion may leave the optional derived projection unready; new reads must report a gap until current-authority promotion/backfill succeeds. Complete-source observation checks prevent an old projection from becoming current stock. The source snapshot foreign key cascade remains installed even when an older binary performs the existing purge.

Ephemeral PostgreSQL tests exercise upgrade from pre-projection complete snapshots, rollback-compatible source replacement/purge, wrong authority tuples, incomplete promotion refusal, complete-empty publication and projection atomicity. They also exercise departure/re-entry, lifecycle, generation and disclosure/activation changes. Immediate read revocation and the existing 24-hour physical purge deadline remain mandatory. Those tests are not measured target purge throughput or a live older-binary rollback drill.
