# Changelog

## 3.0.0 - 2026-09-05

Initial package contract for the EVE Space deployment.

### Added

- Stable package entries for the complete natural Hey API type and Zod surfaces.
- Repository-maintained ESI request execution, domain clients, operation discovery, validation, metadata, and mutation safety.
- TypeScript and Zod 4 artifacts are generated by exactly `@hey-api/openapi-ts@0.99.0` as internal build-time tooling; the published package retains its repository-maintained SDK runtime and contains no Hey API client runtime.
- `generate` and `generate:check` reproduce output offline from the committed corrected OpenAPI snapshot. `generate:source:refresh` is the only networked path and preserves validation, corrections, canonical hashes, and provenance.
- Changes to the exact generator pin require full generation, semantic, package, and installed-tarball validation.
