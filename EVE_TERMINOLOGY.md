# EVE Online Terminology

Reference glossary for EVE Online jargon, kept alongside the codebase so UI copy can use terms
players actually recognize instead of invented labels (e.g. "capsuleer" is standard EVE usage;
"dossier" is not).

Source: [everookies.com/eve-online-terminology](https://everookies.com/eve-online-terminology/)

## Generic Game Terms

- **AFK:** Away from keyboard
- **Alt:** Alternative characters, on same or different accounts
- **Aggro:** Hostile action by player or NPC
- **Authenticator:** Two-factor verification for account security
- **Character name:** Name of your in-game character
- **DPS:** Damage per second output
- **GTFO:** Get away immediately
- **HP:** Hit points
- **Main:** Your primary character
- **Multiboxing:** Playing multiple accounts simultaneously (Omega only)
- **NPC:** Non-player characters
- **PvE:** Player versus environment
- **PvP:** Player versus player
- **Spam:** Rapid repeated button/mouse clicking
- **Username:** Account login name

## Account Terminology

- **Alpha:** Free account (5 million skill point limit)
- **Alpha injector:** Daily skill point injection for Alpha accounts
- **NES:** New Eden Store for cosmetics and game time
- **Omega:** Paid premium account
- **Plex:** In-game currency purchased with real money, convertible to ISK

## EVE Online Core Terms

- **1v1:** One-on-one PvP combat
- **ABC:** Always be cloaked (covert ops reference)
- **Alpha damage:** Initial burst overwhelming resistances
- **Bait:** Deceptive ship or situation
- **Bees:** Reference to Goonswarm Federation alliance
- **Blob:** Being outnumbered 2-3x in fleet combat
- **Blues:** Friendly players/corps/alliances
- **Blueprints:** Crafting items for ships and modules
- **Bombers Bar:** NPSI community for covert ops fleets
- **Bump:** Colliding with another ship to disable actions
- **Carebear:** Non-PvP focused player
- **Covert Ops:** Ship class with cloak capability
- **CSM:** Council of Stellar Management (10 player representatives)
- **Dockup:** Fleet staging location
- **Doctrine:** Standardized fleet ship fits
- **ISK:** In-game currency
- **EHP:** Effective hit points (including resistances)
- **Explo:** Exploration activity
- **Faction:** Gallente, Caldari, Minmatar, or Amarr
- **Faction Warfare:** Low-sec PvP between factions
- **Fleet:** In-game grouping mechanism
- **Ganker:** Player attacking unsuspecting PvE pilots
- **GF:** "Good fight" (or alternate meaning in some contexts)
- **GPS:** System location request
- **Goon:** Goonswarm Alliance member
- **HTFU:** "Harden up" / accept losses
- **Incursion:** High-end PvE fleet content (10-40 pilots)
- **Killboard:** Third-party stat tracking website
- **Kill right:** Permission to attack without consequence
- **Jita 4-4:** Primary trade hub
- **Jump gate:** System transition portal
- **LP:** Loyalty Points from missions/incursions
- **Market:** Player item trading system
- **Neut:** Neutral (non-hostile, non-friendly)
- **Newbro:** New player or activity newcomer
- **NPE:** New player experience
- **NPSI:** "Not purple shoot it" (fleet ally playstyle)
- **Overview:** Critical UI window showing space objects
- **Ping:** Bookmark 150k+ away, or Discord notification
- **Poitot:** Only named system in Syndicate
- **Purple:** Same-fleet players
- **Rats:** NPC pirates
- **Reds:** Hostile players/corps/alliances
- **Region:** Group of systems
- **Safety:** Status indicator (green/yellow/red dot)
- **Safe spot:** Empty space location away from celestials
- **Sec Status:** Security rating (low = high-sec penalties)
- **SISI:** EVE test server
- **Skill queue:** Training queue (trains while offline)
- **Staging:** Fleet gathering location
- **System:** Zone equivalent in EVE
- **Tether:** Docking access repair buff in player structures
- **Trade hub:** Market hub for selling items
- **Tranquility:** Live production server
- **Wormhole:** Temporary rifts connecting systems

## Ship Terminology

- **AF:** Assault Frigate
- **Battlecruiser:** Medium-large ship class
- **Cepter:** Interceptor
- **Cruiser:** Medium-sized ship
- **Destroyer:** Small-powerful ship class
- **Frigate:** Smallest, fastest ships
- **HIC:** Heavy interdiction cruiser (creates large bubbles)
- **Logi:** Logistics/repair ship
- **Subcap:** Non-capital sized ship

## Module Terminology

- **High slot:** Weapon and utility modules
- **Low slot:** Passive and repair modules
- **Mid slot:** Propulsion, shields, electronic warfare
- **Rig slots:** Permanent module upgrades
- **Cloak:** Three types (standard, covert ops, jump)
- **AfterBurner:** Speed boost (130-200%)
- **Microwarpdrive:** Faster boost (500-700%) with sig radius increase

## PvE Terminology

- **Assault incursion sites:** 20-21 pilot incursions
- **DDD:** Drone bunny (designated drone target)
- **Exploration:** Cosmic anomaly hacking
- **Headquarters incursion:** 40-pilot incursion sites
- **Vanguard incursion:** 10-13 pilot incursion sites
- **Krabbing:** ISK-making PvE activities
- **Ratting:** NPC hunting in belts/anomalies

## Fleet Terminology

- **-1:** Player leaving fleet
- **AAR:** After action report (post-fleet analysis)
- **Align:** Orient ship toward destination
- **Backseat:** Senior FC overseeing junior FC
- **Blap:** Destroy target
- **Blops:** Black ops battleship
- **Bounce:** Warp away to celestial
- **Bubble:** Warp disrupt bubble (mobile or ship-generated)
- **Burn:** Full speed travel or return to gate
- **Check check:** Request for comms silence
- **Cold warp:** Warp without alignment
- **Comms:** Voice chat
- **Drone bunny:** Designated drone assignment target
- **EWAR only:** Apply only electronic warfare, no damage
- **JFC:** Junior FC (trainee fleet commander)
- **FC:** Fleet commander
- **Fleet warp:** Commander warps entire fleet
- **Gate is GREEN:** Safe to jump
- **Gate is RED:** Do not jump
- **Hold:** Remain stationary
- **Jump:** Proceed through gate
- **Jump and hold cloak:** Gate jump with no movement
- **Open comms:** No push-to-talk required
- **Push to Talk:** Key/button for voice activation
- **Reps:** Repair modules activate on targets
- **Rookie speech:** Pre-fleet briefing
- **Scatter:** Warp away like "bounce"
- **Slide:** Command to take jump gate
- **Tackle:** Hold target (prevent escape)
- **XUP:** Signal readiness to join fleet
